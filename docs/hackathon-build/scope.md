# Guided-build scope

## Outcome

Release `v0.4.0-rc.1` as an experimental Evidence answer candidate. A person's
AI interprets private circumstances; this static page supplies only bounded,
deterministic, source-linked government evidence and an independently readable
presentation of what that evidence supports and cannot decide.

## Release slice

- correct the current specialist-review source contract without rewriting
  historical evidence;
- retain Technical review and make Evidence answer the default bare route;
- register `present_resource_evidence` as the sixth bounded WebMCP tool;
- project all reviewed and federated records through one closed evidence
  contract;
- verify human/tool parity, accessibility, security and deterministic builds;
- compare 12 natural stories across Microsoft Copilot and pinned local Ollama;
- publish an honestly labelled release candidate and demonstration package.

## Non-goals

- no model, personal profile or conversation history is hosted by the page;
- no runtime call to an official API and no government transaction;
- no eligibility, legal, ownership or live-statistic decision;
- no standalone legislation.gov.uk collection;
- no claim that formative participant research has already occurred;
- no Devpost submission without the separate explicit submission action.
