# Guided-build product requirements

## Canonical PRD

The canonical requirements are
`docs/product/beginner-trust-pathway-prd.md`. The accepted interface contract is
`docs/product/beginner-interface-specification.md`.

## Release acceptance summary

The candidate must:

1. give Evidence answer and Technical review one clear `h1` each;
2. preserve legacy evidence links and reliable browser history;
3. show source, observation, integrity, access, rights, coverage and every
   applicable limitation separately;
4. show the exact structured fields accepted by a successful presentation;
5. state that the page cannot inspect the personal AI's final prose;
6. keep the five existing tools unchanged and add one closed, reversible
   presentation tool;
7. return the same deterministic evidence object that the page renders;
8. cover all 80 reviewed and 58,652 federated records at data level;
9. pass representative Chrome, Edge and accessibility journeys; and
10. retain host comparison, public deployment, release and media evidence
    without implying a Devpost submission.

## Submission proof points

- the personal AI can choose a small Site tool without using a dedicated
  personal-profile field, while free-text arguments retain an explicit
  disclosure warning;
- a non-technical person can independently inspect the evidence supplied;
- the page is static, same-origin, deterministic and source-linked;
- cloud and local hosts are reported as observational alternatives rather than
  a causal model comparison;
- unsupported additions and unsafe conclusions are evaluated separately from
  successful tool calls.
