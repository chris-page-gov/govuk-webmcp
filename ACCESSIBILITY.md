# Accessibility statement

This statement applies to the independent experimental prototype, Trusted
government knowledge discovery.

The human search, record and provenance journey is designed to remain usable
without WebMCP. It uses semantic headings, labelled controls, keyboard-operable
buttons and links, visible focus, status messages and text alternatives where
applicable. Source, assertion and limitation information is available in the
page as well as structured tool output.

## Testing and known limitations

Automated browser tests cover keyboard-reachable controls, responsive reflow,
forced colours, reduced motion and an axe WCAG 2.1 A/AA smoke check. Automated
testing cannot establish WCAG conformance. A manual screen-reader observation
has not yet been completed and is recorded as a release limitation.

The prototype does not claim WCAG conformance or production-service
accessibility. If you find an accessibility problem, open a GitHub issue without
including personal or sensitive information and state the browser, assistive
technology and affected journey.
