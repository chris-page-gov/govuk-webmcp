    What this catalogue does not prove

    • Inclusion does not grant access or permission to use a service.
    • A confirmed licence applies only where the cited record says it does.
    • Digest-bound means the packaged metadata passed integrity checks, not that government certified its accuracy.
    • No official data-provider API or model-provider API is called by this page.

    Why WebMCP matters

    Publish evidence and tools, not another government chatbot

    This page hosts no AI model. It exposes five bounded page tools over static, source-linked evidence. A citizen-selected AI can use what it already knows about the citizen to choose a tool, then send only the necessary search terms or record identifier. The page does not accept a profile, conversation history, personal context or arbitrary URL.

    1. The citizen’s AI understands the situation. Personal context stays outside the government tool input.
    2. WebMCP exposes a small, inspectable action. Closed schemas and executable validation bound every call.
    3. OKF supplies governed evidence. The result carries its source snapshot, assertion state, access, rights and limitations.
    4. The person can check the foundation. Human search returns the same deterministic result without WebMCP.

    Privacy and cost are hypotheses to test, not guarantees. A remote AI provider may receive the prompt, tool description, arguments and result. Only local inference can keep that model interaction on the device. Static hosting still has publication, network, maintenance and assurance costs.

    WebMCP diagnostics

    Registration is progressive enhancement. Instrumented page registration does not by itself prove that a particular agent host discovered or called these tools.
