# Competition compliance checklist

Status values: **confirmed**, **verify**, **approval required**, **blocker**.

## Entrant and dates

- [ ] **Confirmed:** submission uses the live Official Rules deadline: 3 September 2026, 13:00 PDT / 21:00 BST.
- [ ] **Verify:** Devpost registration is complete under the same individual, team or organisation identity used in the submission.
- [ ] **Verify:** entrant remains eligible by age, residence, supported-country status and account requirements.
- [ ] **Approval required:** any team or organisation representative has written authority.
- [ ] **Blocker:** no actual or apparent conflict falls within the rules' exclusions.

## Ownership and rights

- [ ] **Blocker:** signed ownership schedule identifies personally owned, employer-owned, collaborator-owned, open-source and OGL/source-specific material.
- [ ] **Blocker:** entrant can truthfully give every ownership, originality and rights warranty.
- [ ] **Verify:** pre-existing work is disclosed and the judged WebMCP extension is separately evidenced after 25 August 2026 11:00 PDT.
- [ ] **Verify:** top-level repository licence is visible and machine-detectable; third-party notices do not imply a blanket data licence.
- [ ] **Verify:** all copied code, metadata, images, fonts, music, logos and trade marks have a recorded reuse basis.
- [ ] **Verify:** GOV.UK/Crown material carries OGL attribution only where applicable; excluded logos, trade marks, personal data and third-party works are not copied.

## Employment, conflicts, prize and publicity

- [ ] **Approval required:** Warwickshire County Council has determined IP ownership, outside-interest/conflict, resource-use, prize and publicity requirements.
- [ ] **Approval required:** DSIT/BDUK has determined the corresponding secondment-host and apparent-endorsement position where applicable.
- [ ] **Approval required:** a written route exists for cash, credits, equipment, subscriptions, tax paperwork and promotional activity.
- [ ] **Verify:** submission language does not imply endorsement by WCC, DSIT, BDUK, GDS, GOV.UK or another public body.

## Technical submission

- [ ] **Confirmed by test:** public live URL exposes material WebMCP behaviour in the supported judging environments.
- [ ] **Confirmed by test:** page still provides a complete keyboard-accessible manual journey when WebMCP is unavailable.
- [ ] **Confirmed by test:** exactly the declared read-only tools register; inputs and outputs validate; no runtime provider call or credential path exists.
- [ ] **Confirmed by test:** every substantive record has an authoritative human-validation link or an explicit missing-link limitation.
- [ ] **Confirmed by test:** catalogue inclusion is never described as access authority.
- [ ] **Confirmed by test:** signed-out clone/build/deploy instructions reproduce the submission.

## Required artefacts

- [ ] Public source repository with all source/assets/instructions and visible licence.
- [ ] Public live deployment; any demo account credentials supplied if the rules require them.
- [ ] Public YouTube video shorter than three minutes.
- [ ] English text description explaining WebMCP leverage, execution, impact, creativity and boundaries.
- [ ] Immutable release/tag, hashes, provenance manifest, SBOM/notices and submission receipt retained.
